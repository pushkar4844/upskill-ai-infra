Concept primer

RDMA and interconnect

Training moves huge buffers between GPUs every step. RDMA fabrics (InfiniBand, RoCE, AWS EFA) do it without CPU copies; their design and congestion control decide how well jobs scale.

Key ideas

  1. RDMA lets a NIC read or write remote memory directly. Core objects: queue pairs (QP), registered memory regions (MR), protection domains (PD) and completion queues (CQ).
  2. InfiniBand uses credit-based, lossless link-level flow control and a subnet manager. RoCEv2 runs RDMA over UDP (port 4791) on Ethernet and relies on PFC, ECN and DCQCN to avoid loss and congestion.
  3. AWS EFA exposes its SRD transport through libfabric; NCCL reaches it through the aws-ofi-nccl plugin. Security groups must allow all traffic to and from themselves.
  4. Rail-optimised networks connect NIC k of every node to the same leaf switches, so same-rank traffic stays one hop away; cross-rail traffic uses NVLink inside the node.
  5. Health signals: symbol errors, link-downed counts, receive errors, transmit discards and wait counters. Rising counters on one link point to a cable, transceiver or port.

Common mistakes

  • Comparing Soft-RoCE numbers with real NIC numbers (it's a concept lab)
  • NCCL silently falling back to TCP sockets
  • Ignoring oversubscription when sizing spine switches

What interviewers probe

Explain RDMA to a cloud engineer in 60 seconds. NCCL falls back to sockets on an EFA cluster: first three checks?

Practise it

  1. E1RDMA from zero on Soft-RoCERDMA lets one machine write into another's memory without the remote CPU. It's what InfiniBand/RoCE/EFA give NCCL. Soft-RoCE emulates it in software on any NIC, so you learn the commands and concepts for free. Phase 1Core6 hV
  2. E2EFA on AWS, validated like a field engineer wouldBring up two EFA nodes, prove EFA is used by NCCL, and record the version matrix. Phase 2Core10 hG2N
  3. E3InfiniBand diagnostics cheat sheet (study task)InfiniBand can't be emulated cheaply. Learn the tools and counters well enough to read real output, then confirm on borrowed hardware. Phase 2Core8 hL
  4. E5GPUDirect RDMA and the storage pathProve data goes NIC <-> GPU memory directly and see topology affect it. Needs ConnectX or EFA nodes that support GPUDirect RDMA (e.g. AWS p4d/p5) - usually rented or borrowed. Phase 28 hR
  5. E4Design a 512-GPU fabric on paperDesign the network for 64 nodes x 8 GPUs: rail-optimized leaf-spine, cable counts, oversubscription, congestion control. Phase 312 hL

Terms

DCQCN
Data Center Quantized Congestion Notification: congestion control for RoCE using ECN marks.
EFA
Elastic Fabric Adapter: AWS network interface for HPC/AI with an OS-bypass transport (SRD) used through libfabric.
GPUDirect RDMA
NIC reads and writes GPU memory directly, bypassing host memory.
InfiniBand
Lossless, credit-based high-performance fabric managed by a subnet manager; common in large training clusters.
PFC / ECN
Priority Flow Control (pause frames for lossless classes) and Explicit Congestion Notification (marking packets), used together in RoCE networks.
Rail-optimised
Fabric layout where NIC k of every node connects to the same set of leaf switches.
RDMA
Remote Direct Memory Access: a NIC reads or writes remote memory without the remote CPU or kernel copies.
RoCEv2
RDMA over Converged Ethernet, version 2: RDMA carried in UDP (port 4791) over IP networks.
