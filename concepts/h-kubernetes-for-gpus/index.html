Concept primer

Kubernetes for GPUs

On Kubernetes, GPUs arrive through operators and device APIs. The hard parts are sharing GPUs, scheduling whole jobs at once, giving pods RDMA, and remediating bad nodes safely.

Key ideas

  1. The GPU Operator installs driver (optional), container toolkit, device plugin, GPU feature discovery, DCGM exporter and validators as DaemonSets.
  2. The device plugin advertises a count (nvidia.com/gpu). Dynamic Resource Allocation (GA since Kubernetes v1.34) lets claims select devices by attributes and handle groups such as NVLink domains.
  3. Sharing: time-slicing (no isolation), MPS (concurrent kernels, limited isolation), MIG (hardware partitions of memory and compute on A100/H100-class GPUs).
  4. Distributed jobs need gang scheduling: start all pods or none. Kueue provides quota, borrowing and all-or-nothing admission (API v1beta2 since v0.20); KAI Scheduler and Volcano are alternatives.
  5. The Network Operator plus Multus and an RDMA device plugin give pods a secondary RDMA interface; Node Problem Detector plus a remediator handle bad nodes.

Common mistakes

  • Time-slicing for tenants that need isolation
  • Partial gang starts that hold GPUs and deadlock the queue
  • Remediation without a maxUnhealthy limit

What interviewers probe

What does the GPU Operator install, and in what order? Two teams share 256 GPUs: how do you enforce quota and avoid deadlock?

Terms

Circuit breaker
A limit that stops automated remediation when too many nodes look unhealthy at once.
Device plugin
Kubernetes mechanism that advertises devices such as nvidia.com/gpu as countable node resources.
DRA
Dynamic Resource Allocation: Kubernetes API (GA in v1.34) for claiming devices by attributes via ResourceClaims and DeviceClasses.
Gang scheduling
Starting all pods or processes of a distributed job together, or none of them.
MIG
Multi-Instance GPU: hardware partitioning of A100/H100-class GPUs into isolated instances.
MPS
Multi-Process Service: lets several processes share a GPU concurrently with limited isolation.
