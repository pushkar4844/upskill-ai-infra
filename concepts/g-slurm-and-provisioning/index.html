Concept primer

Slurm and provisioning

Most large training clusters run Slurm; many companies run Kubernetes or both. You need to operate Slurm, keep bad nodes out of the queue and know how servers become nodes in the first place.

Key ideas

  1. Slurm: slurmctld (controller), slurmd (per node), partitions, sbatch/srun/squeue/sacct. GPUs are generic resources (GRES) declared in gres.conf.
  2. With cgroup ConstrainDevices a job sees only its allocated GPUs (exposed through CUDA_VISIBLE_DEVICES).
  3. Prolog, epilog and Node Health Check (NHC) drain unhealthy nodes before jobs land on them.
  4. Pyxis + Enroot let Slurm jobs run containers unprivileged (srun --container-image).
  5. Provisioning: BMC power-on, PXE/iPXE boot, image, config management, burn-in, then join the scheduler. Tools: Warewulf, MAAS, Ironic, Metal3, Tinkerbell.

Common mistakes

  • gres.conf and the NodeName line disagreeing on GPU count
  • Health checks that only run at boot
  • Picking Slurm vs Kubernetes on taste instead of on users, tenancy and operations

What interviewers probe

How does Slurm keep one job's GPUs invisible to another? A customer asks Slurm or Kubernetes for training: how do you answer?

Practise it

  1. G1Slurm in Docker with fake GPUsSlurm is the HPC scheduler used for most large training clusters. Learn the daily commands and how GPUs are declared (GRES) on a laptop. Phase 16 hL
  2. G2Slurm on real GPU nodes with containers and health checksA real single-node Slurm with GPUs, container jobs (Pyxis/Enroot) and Node Health Check. Phase 2Core12 hG4
  3. G3Provision the same cluster on three cloudsKnow how each hyperscaler builds HPC/AI clusters. Build one for real (AWS ParallelCluster), read the other two. Phase 214 hG2N
  4. G5Rack to OS: PXE-boot a cluster you builtSee how a bare server becomes a node: DHCP, PXE/iPXE, kernel+image, config. Uses VirtualBox on your laptop, no nested virtualization needed. Phase 212 hL
  5. G4Slurm on Kubernetes decision memo (Slinky, Soperator, Kueue)Customers ask 'Slurm or Kubernetes?'. Try Slinky on kind and write a decision memo. Phase 310 hL

In the job posting

  • BMC, IPMI, Redfish, out-of-band debugging
  • Stand-out: hyperscaler compute and networking knowledge

Terms

Enroot / Pyxis
NVIDIA tools to run containers unprivileged on HPC systems; Pyxis adds srun --container-image to Slurm.
GRES
Slurm generic resources, such as GPUs, declared in gres.conf and requested with --gres.
NHC
Node Health Check: HPC framework run as a Slurm health check or prolog to drain bad nodes.
