Why it matters

Solve problems involving distributed system interactions.

Gives evidence for these requirements in the posting:

  • CUDA, NCCL, NVSwitch/NVLink, drivers, performance tuning
  • Find bottlenecks at cluster, node, accelerator, network, application layers

New to nccl and collectives? Read the 5-minute primer first.

What done looks like

Deliverable. Incident report and the repro scripts.
The outcome, step by step (field manual version)
  1. Write a torchrun loop that does all-reduce in a loop. Make one rank slow, for example by sleeping or reducing that GPU's power limit.
  2. Reproduce a hang by killing one rank and watch what the others do. Collect NCCL_DEBUG=INFO plus NCCL_DEBUG_SUBSYS logs.
  3. Add straggler detection from NVIDIA's resiliency extension and compare it to what you saw by hand.
  4. Try fault-tolerant training with torchft semantics and note what recovers automatically.
  5. Write an incident report in the form: symptom, hypotheses, evidence, fix.

Hands-on steps

  1. 4-GPU node, PyTorch installed (DL AMI has conda/pip - create a venv with torch).
    python3 -m venv ~/v && . ~/v/bin/activate && pip install torch
  2. Straggler script.
    cat > ar_loop.py <<'EOF'
import os, time, datetime, torch, torch.distributed as dist
dist.init_process_group('nccl', timeout=datetime.timedelta(seconds=60))
r = dist.get_rank(); torch.cuda.set_device(int(os.environ['LOCAL_RANK']))
x = torch.ones(64*1024*1024, device='cuda')
slow = int(os.environ.get('SLOW_RANK', -1))
for i in range(500):
    if r == slow: time.sleep(0.2)
    t = time.time(); dist.all_reduce(x); torch.cuda.synchronize()
    if r == 0 and i % 10 == 0: print(i, f'{(time.time()-t)*1000:.1f} ms', flush=True)
dist.destroy_process_group()
EOF
torchrun --nproc_per_node=4 ar_loop.py
SLOW_RANK=2 torchrun --nproc_per_node=4 ar_loop.py     # every rank's step time jumps
  3. Hang: kill one rank mid-run and watch the others.
    NCCL_DEBUG=INFO TORCH_NCCL_ASYNC_ERROR_HANDLING=1 torchrun --nproc_per_node=4 ar_loop.py &
sleep 20; pkill -9 -f 'ar_loop.py' -n    # kills newest rank
# observe: others block until the 60 s timeout, then error
  4. Get stacks from a hung process.
    pip install py-spy && sudo ~/v/bin/py-spy dump --pid <pid>
  5. Read nvidia-resiliency-ext straggler detection and torchft docs (Go deeper); try their example if time allows.
  6. Incident report: symptom, hypotheses, evidence, fix.
You should see. With SLOW_RANK all ranks slow down equally (collectives wait for the slowest). Killing a rank makes others hang until the NCCL/PG timeout.

Interview

Be ready for: A 64-GPU job hangs after 4 hours. How do you find the cause?

Show the answer you can now give

Hang after hours: find which rank stopped (NCCL_DEBUG, flight recorder, py-spy dumps), check that node's dmesg for XIDs, NIC errors and OOM, check for a straggler via per-rank step times, then bisect nodes if it's fabric.
