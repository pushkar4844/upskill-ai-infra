Why it matters

NUMA, memory subsystem behavior, node-level performance analysis.

Gives evidence for these requirements in the posting:

  • Server hardware: PCIe, firmware, NUMA, BIOS/UEFI, power and thermal

New to server hardware and topology? Read the 5-minute primer first.

What done looks like

Deliverable. Results table plus a paragraph you can say out loud in 30 seconds.
The outcome, step by step (field manual version)
  1. List test cases with nvbandwidth -l and pick host-to-device and device-to-host copies.
  2. Run them under numactl --cpunodebind=<local> --membind=<local>, then with the remote node.
  3. Repeat while a memory-bandwidth hog runs on the local socket to show contention.
  4. Capture memory controller traffic with Intel PCM if your CPU supports it.
  5. Build a table of local versus remote bandwidth and latency with the percentage penalty.

Hands-on steps

  1. You need a 2-socket instance. Check with numactl -H (2 nodes). On AWS that means larger sizes (e.g. g4dn.metal, g5.48xlarge) - check numactl -H before running; on a single-node box you can only show the method.
    numactl -H; nvidia-smi topo -m
  2. Build nvbandwidth.
    sudo apt install -y cmake libboost-program-options-dev
git clone https://github.com/NVIDIA/nvbandwidth && cd nvbandwidth && cmake . && make -j
./nvbandwidth -l | head -30
  3. Local vs remote socket for GPU0 (from topo -m: CPU Affinity / NUMA Affinity column).
    numactl --cpunodebind=0 --membind=0 ./nvbandwidth -t host_to_device_memcpy_ce -d 0
numactl --cpunodebind=1 --membind=1 ./nvbandwidth -t host_to_device_memcpy_ce -d 0
# repeat for device_to_host_memcpy_ce
  4. Add memory contention on the local socket and repeat.
    numactl --cpunodebind=0 --membind=0 stress-ng --stream 8 --timeout 120 &
  5. Table: local vs remote bandwidth, % penalty. Write the 30-second explanation.
You should see. Remote-socket runs show lower host<->device bandwidth (the copy crosses the CPU interconnect).

Interview

Be ready for: Why does CPU socket placement matter for a GPU and a NIC?

Show the answer you can now give

A GPU and its NIC hang off one socket's PCIe root. If the process and its memory live on the other socket, every copy crosses the inter-socket link, cutting bandwidth and adding latency - so we bind ranks to the local NUMA node and NIC.
