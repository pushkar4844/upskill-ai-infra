DCGM diagnostics, levels 1 to 4

DCGM is NVIDIA's data-center GPU manager. Its diag levels are how fleets prove a GPU is healthy. Learn what each level runs and how long it takes.

Where
G1 One GPU, spot (g4dn.xlarge T4 16 GB or g5.xlarge A10G 24 GB)
Time
6 hours
Cost
~$1-2
Do first
S8, B1

Why it matters

Hands-on bring-up and validation of large-scale NVIDIA GPU platforms.

Gives evidence for these requirements in the posting:

  • Bring-up and validation of multi-GPU and multi-node NVIDIA platforms

New to gpu health and diagnostics? Read the 5-minute primer first.

What done looks like

Deliverable. dcgm_report.py and a table of your timings versus the docs.
The outcome, step by step (field manual version)
  1. Install DCGM and run dcgmi discovery -l.
  2. Run dcgmi diag -r 1, then -r 2, then -r 3 --fail-early. Save JSON with -j.
  3. Compare your timings with the documented Hopper figures: r1 under 2.5 s, r2 under 10.5 min on 8 GPUs, r3 under 35 min on 8 GPUs, r4 under 2.25 h on 8 GPUs.
  4. Write down which plugins each level adds: r2 adds PCIe/NVLink, memory and memory bandwidth; r3 adds diagnostic, targeted stress, targeted power, NVBandwidth and NCCL tests; r4 adds memtest and pulse.
  5. Write a parser that turns the JSON into pass/fail per GPU per plugin.

Hands-on steps

  1. Start a GPU instance (g4dn.xlarge is fine).
    cd ~/gpu-lab/infra/gpu1 && terraform apply
aws ssm start-session --target $(terraform output -raw id)
sudo -iu ubuntu; nvidia-smi
  2. Check DCGM. The Deep Learning Base AMI already includes DCGM 4, so this usually just starts the service. If dcgmi is missing (plain Ubuntu), install the package that matches your driver's CUDA major version, as NVIDIA's DCGM guide does.
    dcgmi --version || {
  CUDA_VERSION=$(nvidia-smi -q | sed -E -n 's/CUDA Version[ :]+([0-9]+)[.].*/\1/p')
  sudo apt-get update
  sudo apt-get install -y --install-recommends datacenter-gpu-manager-4-cuda${CUDA_VERSION}
}
sudo systemctl --now enable nvidia-dcgm
dcgmi discovery -l
  3. Run levels 1, 2, 3 and save JSON. Time each one.
    mkdir -p ~/dcgm && cd ~/dcgm
for r in 1 2 3; do /usr/bin/time -f "r$r %e s" dcgmi diag -r $r -j > r$r.json; done
jq 'keys' r1.json      # look at the structure before parsing
  4. Read which plugins each level adds (the DCGM docs in Go deeper list them). Optional: r4 takes hours - skip on a T4 unless you want the experience.
  5. Write a parser. The JSON layout differs between DCGM 3 and 4, so this walks the tree and prints any test name + result it finds - adjust once you've seen your file.
    cat > ~/dcgm/dcgm_report.py <<'EOF'
#!/usr/bin/env python3
import json, sys
def walk(o, path=""):
    if isinstance(o, dict):
        name = o.get("name") or o.get("test_name")
        res = o.get("status") or o.get("result")
        if name and res:
            print(f"{name:35} {res}")
        for k, v in o.items():
            walk(v, f"{path}/{k}")
    elif isinstance(o, list):
        for v in o:
            walk(v, path)
for f in sys.argv[1:]:
    print("==", f); walk(json.load(open(f)))
EOF
python3 ~/dcgm/dcgm_report.py r1.json r2.json r3.json
  6. Also try health watches and live fields.
    dcgmi health -s a          # enable all watches on group 0
dcgmi health -c
dcgmi dmon -e 150,155,203,204 -c 5   # temp, power, gpu util, mem copy util (field IDs)
  7. Copy results to your repo (print/paste or S3), destroy.
    terraform destroy -auto-approve
You should see. discovery lists 1 GPU. r1 finishes in seconds, r2 in minutes, r3 tens of minutes on a T4. All tests Pass on a healthy GPU.

If it breaks

SymptomFix
dcgmi: Unable to connect to host enginesudo systemctl status nvidia-dcgm; start it; or run nv-hostengine manually
Diag skips tests 'not supported'Some plugins need specific GPUs/NVLink - note it, that's a finding
Package not foundThe CUDA apt repo must be configured first (NVIDIA CUDA installation guide). On Maxwell/Pascal/Volta GPUs with driver 580 use the -cuda12 package

Interview

Be ready for: What does dcgmi diag -r 3 run that -r 2 does not, and when would you pay for -r 4 ?

Show the answer you can now give

r1 is a seconds-long sanity check, r2 adds PCIe/NVLink and memory tests, r3 adds stress, power, bandwidth and NCCL plugins and takes ~30 min on 8 GPUs, r4 adds memtest/pulse for hours. I run r3 at acceptance and r1 at job start.
