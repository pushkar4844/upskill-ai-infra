About this phase

Phase 2 is the longest and most important phase. Phase 1 showed you each layer once; now you go deep on each one and start working across nodes, which is where real clusters fail. You reproduce real failure modes on purpose and measure their effect with numbers.

Expect to break things: throttle a GPU, pin a process to the wrong CPU socket, run NCCL with and without EFA, hang an all-reduce, make one node a straggler. Each time you learn the symptom, the tool that shows it and the fix, which is exactly what a field engineer does during cluster bring-up.

This phase also widens your view from one node to the platform: drivers and containers, BMC firmware, bare-metal provisioning, three clouds' cluster designs, GPU sharing and gang scheduling on Kubernetes, metrics and alerting, and enough of the training and serving workloads to talk to the people who run them.

By the end you can

  • Burn in a GPU and prove throttling with clock-event reasons
  • Measure NUMA and PCIe effects with nvbandwidth and pcie_check.sh
  • Bring up EFA, prove NCCL uses it, and measure 1-node vs 2-node scaling
  • Debug an all-reduce hang and a straggler
  • Run Slurm with real GPUs, containers and Node Health Check
  • Operate GPU sharing (time-slicing, MIG), gang scheduling and DRA on Kubernetes
  • Build a DCGM to Prometheus to Grafana pipeline with alerts

How the phase runs

  1. Node depth

    Linux, containers and drivers (A2–A4), burn-in and remediation (B3–B4), NUMA and PCIe (C2–C3), OpenBMC (D2). Mostly one spot GPU.

  2. Across nodes

    EFA, InfiniBand and GPUDirect (E2, E3, E5), scaling and failures (F2, F3). Book the two-node EFA sessions together.

  3. Clusters

    Slurm with real GPUs, three clouds, PXE provisioning (G2, G3, G5).

  4. Platform

    Kubernetes GPU features (H2–H5), cloud instance decoding (I1), metrics and alerts (J1), workload literacy (K2–K4). Then the checkpoint.

Tips

  • Run E2 and F2 in the same EFA session, and keep the session to 2–3 hours.
  • Keep a failure log: symptom, cause, fix. It becomes your interview stories.
  • Labs H3–H5 are free on your laptop; do them while waiting for GPU quota or between paid sessions.
  • Book an NCP-AII exam date about halfway through this phase as a deadline.
