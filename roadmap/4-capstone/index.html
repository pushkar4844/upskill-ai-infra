About this phase

Phase 4 turns 48 labs into one repository and one story. The capstone is a validation kit: one command builds a two-node GPU cluster with Terraform, configures it with Ansible, runs your acceptance stages and writes a dated go/no-go report, then tears everything down.

To show the kit works, you inject failures and prove each one is caught: a simulated XID line, EFA disabled, a NUMA mis-binding, a slow node. A README with the architecture, the results and the cost per run makes the repository readable in five minutes.

The second lab makes the work visible: posts about what you learned, two pull requests to open-source projects you used, and a 10-minute talk built on the capstone. You finish by answering the interview bank out loud.

How the phase runs

  1. Build

    Assemble scripts from earlier labs into make up / configure / validate / down, driven by a criteria file.

  2. Break

    Inject each failure and make sure the report marks it as a no-go with the right evidence.

  3. Show

    README, diagram, results and cost; posts, pull requests and a 10-minute talk (L2).

Tips

  • Make the kit fail loudly and clearly; a clear no-go report is more impressive than a green one.
  • Record a short demo video in case a live demo isn't possible.
  • Practise the walkthrough: what it checks, what it caught, what a run costs, what changes at 2,000 GPUs.
