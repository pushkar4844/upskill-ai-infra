Glossary

Short definitions. Each term links to the lab where you meet it first.

OverviewHidden gemsReadingCertificationsWhen you're stuckGlossary
AER
PCIe Advanced Error Reporting: kernel counters and messages for correctable and uncorrectable PCIe errors. Lab C3 →
algbw / busbw
nccl-tests bandwidth figures. algbw = bytes/time; busbw applies an algorithm factor (all-reduce 2(n-1)/n) so it compares with link bandwidth. Lab F1 →
All-reduce
Collective that sums (or otherwise reduces) a buffer across all ranks and gives every rank the result. Used for gradients in data-parallel training. Lab F1 →
BMC
Baseboard Management Controller: an independent controller on the server board for sensors, logs, console and power control. Lab D1 →
Burn-in
Hours of stress on new hardware while logging temperature, power, clocks and errors, to catch early failures before customers do. Lab B3 →
CDI
Container Device Interface: a declarative spec describing device nodes and mounts for a container runtime. Lab A3 →
Circuit breaker
A limit that stops automated remediation when too many nodes look unhealthy at once. Lab H6 →
Clock-event reasons
nvidia-smi fields explaining why GPU clocks are lowered (power cap, thermal, hardware slowdown). Formerly called throttle reasons. Lab B3 →
Collective
A communication operation involving a group of ranks: all-reduce, all-gather, reduce-scatter, all-to-all, broadcast. Lab F1 →
DCGM
NVIDIA Data Center GPU Manager: health, diagnostics (levels r1-r4), policy and telemetry for data-center GPUs. Lab B2 →
dcgm-exporter
Exports DCGM fields as Prometheus metrics. Lab J1 →
DCQCN
Data Center Quantized Congestion Notification: congestion control for RoCE using ECN marks. Lab E4 →
Device plugin
Kubernetes mechanism that advertises devices such as nvidia.com/gpu as countable node resources. Lab H1 →
DRA
Dynamic Resource Allocation: Kubernetes API (GA in v1.34) for claiming devices by attributes via ResourceClaims and DeviceClasses. Lab H5 →
ECC
Error-correcting code memory. Single-bit errors are corrected; double-bit (uncorrectable) errors kill the affected work. Lab B1 →
EFA
Elastic Fabric Adapter: AWS network interface for HPC/AI with an OS-bypass transport (SRD) used through libfabric. Lab E2 →
Enroot / Pyxis
NVIDIA tools to run containers unprivileged on HPC systems; Pyxis adds srun --container-image to Slurm. Lab G2 →
Gang scheduling
Starting all pods or processes of a distributed job together, or none of them. Lab H4 →
GPUDirect RDMA
NIC reads and writes GPU memory directly, bypassing host memory. Lab E5 →
GRES
Slurm generic resources, such as GPUs, declared in gres.conf and requested with --gres. Lab G1 →
HGX
NVIDIA's multi-GPU server baseboard design (e.g. 8 GPUs connected by NVSwitch). Lab C1 →
InfiniBand
Lossless, credit-based high-performance fabric managed by a subnet manager; common in large training clusters. Lab E3 →
IPMI
Older binary protocol for out-of-band server management; largely superseded by Redfish. Lab D2 →
KV cache
Stored attention keys and values for generated tokens; its size per token sets how many sequences fit on a GPU. Lab K1 →
MFU
Model FLOPs Utilization: achieved model FLOPs divided by the hardware's peak FLOPs. Lab K2 →
MIG
Multi-Instance GPU: hardware partitioning of A100/H100-class GPUs into isolated instances. Lab H2 →
MPS
Multi-Process Service: lets several processes share a GPU concurrently with limited isolation. Lab H2 →
NCCL
NVIDIA Collective Communications Library: GPU-to-GPU collectives over NVLink, PCIe and networks. Lab F1 →
NHC
Node Health Check: HPC framework run as a Slurm health check or prolog to drain bad nodes. Lab G2 →
NUMA
Non-Uniform Memory Access: memory and devices attached to one CPU socket are faster for that socket. Lab C2 →
NVLink / NVSwitch
NVIDIA's high-bandwidth GPU-to-GPU links and the switch chips that connect all GPUs in a node. Lab C1 →
PFC / ECN
Priority Flow Control (pause frames for lossless classes) and Explicit Congestion Notification (marking packets), used together in RoCE networks. Lab E4 →
Rail-optimised
Fabric layout where NIC k of every node connects to the same set of leaf switches. Lab E4 →
RDMA
Remote Direct Memory Access: a NIC reads or writes remote memory without the remote CPU or kernel copies. Lab E1 →
Redfish
DMTF standard REST/JSON API for server management exposed by BMCs. Lab D1 →
RoCEv2
RDMA over Converged Ethernet, version 2: RDMA carried in UDP (port 4791) over IP networks. Lab E1 →
Row remapping
Replacing bad GPU memory rows with spares; pending remaps apply after a GPU reset (XID 63 event, XID 64 failure). Lab B1 →
SEL
System Event Log kept by the BMC: power, thermal and hardware events. Lab D2 →
Straggler
A rank slower than the others; collectives wait for it, so it slows the whole job. Lab F3 →
TTFT / ITL
Time to first token and inter-token latency: the two main latency metrics for LLM serving. Lab K4 →
XID
NVIDIA driver error code written to the kernel log as 'NVRM: Xid'. Lab B1 →
Young/Daly interval
Optimal checkpoint interval ~ sqrt(2 x checkpoint cost x mean time between failures). Lab K3 →
