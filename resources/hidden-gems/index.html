NVIDIA/cluster-readiness-engine

NVIDIA's open-source Kubernetes controller for workload-driven cluster validation, with thresholds you define and adaptive fault isolation.

Used in B5, F4

NVIDIA/aicr

AI Cluster Runtime: checks that drivers, operators, kernels and settings match what a cluster should have.

Used in B5

NVIDIA/NVSentinel

Detects GPU faults from DCGM, syslog and cloud events, then cordons, drains and remediates with a circuit breaker.

Used in B4, H6

Discovers network topology and feeds it to Kubernetes and Slurm so jobs land close together.

Used in E4, G4

Fault tolerance, straggler detection, async and local checkpointing for large training jobs.
