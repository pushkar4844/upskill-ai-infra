Install WSL2 + Ubuntu 24.04 on Windows

Why

Your Windows laptop becomes a Linux workstation. Open PowerShell as Administrator. Reboot when asked, then open 'Ubuntu' from the Start menu and create a Linux user.

Do it

wsl --install -d Ubuntu-24.04
wsl --set-default-version 2
wsl -l -v        # should show Ubuntu-24.04  VERSION 2
You should see. Ubuntu-24.04 listed with VERSION 2. Also install Windows Terminal and VS Code with the 'WSL' extension; open your lab folder with code . from Ubuntu.
