Terraform: two EFA nodes (environment G2N) - only when you reach E2/F2

Why

Copy infra/gpu1 to infra/efa2 and change: count = 2, instance_type = an EFA-capable GPU size (check with the first command below; g4dn.12xlarge is the usual low-cost choice), a cluster placement group, and an EFA network interface instead of subnet_id/vpc_security_group_ids. EFA also needs the security group to allow all outbound traffic to itself - the rule below covers it. On-demand is safer than spot for multi-node. Two g4dn.12xlarge = 96 vCPU, so raise the On-Demand G and VT quota to 96 first.

Do it

# 1) Which GPU sizes support EFA in your region?
aws ec2 describe-instance-types --filters Name=network-info.efa-supported,Values=true Name=instance-type,Values='g4dn.*','g5.*','g6.*','g6e.*' \
  --query 'sort(InstanceTypes[].InstanceType)' --output text

# 2) main.tf changes
resource "aws_placement_group" "pg" { name = "lab-efa"  strategy = "cluster" }

resource "aws_security_group_rule" "self_egress" {
  type = "egress"  from_port = 0  to_port = 0  protocol = "-1"
  security_group_id = aws_security_group.gpu.id  source_security_group_id = aws_security_group.gpu.id
}

resource "aws_instance" "gpu" {
  count           = 2
  ami             = data.aws_ami.dlami.id
  instance_type   = "g4dn.12xlarge"
  placement_group = aws_placement_group.pg.id
  iam_instance_profile = aws_iam_instance_profile.ssm.name
  network_interface {
    device_index         = 0
    network_interface_id = aws_network_interface.efa[count.index].id
  }
  root_block_device { volume_size = 150  volume_type = "gp3" }
  user_data = "#!/bin/bash\nshutdown -h +180\n"
  instance_initiated_shutdown_behavior = "terminate"
  tags = { Name = "lab-efa-${count.index}" }
}
resource "aws_network_interface" "efa" {
  count           = 2
  subnet_id       = data.aws_subnets.default.ids[0]
  security_groups = [aws_security_group.gpu.id]
  interface_type  = "efa"
}
output "ids" { value = aws_instance.gpu[*].id }
output "ips" { value = aws_network_interface.efa[*].private_ip }
You should see. Both nodes up; on each fi_info -p efa -t FI_EP_RDM lists the efa provider. Budget: run 2-3 hours, then terraform destroy.
