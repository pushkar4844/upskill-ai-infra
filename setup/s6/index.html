Install Terraform and create your portfolio repo

Why

Everything you build goes into one Git repo. This is what you show in interviews.

Do it

wget -O- https://apt.releases.hashicorp.com/gpg | sudo gpg --dearmor -o /usr/share/keyrings/hashicorp.gpg
echo "deb [signed-by=/usr/share/keyrings/hashicorp.gpg] https://apt.releases.hashicorp.com $(lsb_release -cs) main" | sudo tee /etc/apt/sources.list.d/hashicorp.list
sudo apt update && sudo apt install -y terraform

mkdir -p ~/gpu-lab && cd ~/gpu-lab && git init
mkdir -p infra/{vms,gpu1,efa2} linux gpu-health topology bmc rdma nccl slurm k8s cloud observability llm capstone notes results
cat > README.md <<'EOF'
# GPU Bring-up Lab
Hands-on journal for GPU infrastructure (NVIDIA SA Infrastructure prep).
Each folder = one domain. Each lab = script + results/ + notes/<lab>.md (what I did, what broke, what I learned).
EOF
git add . && git commit -m "lab skeleton"
You should see. tree -L 1 ~/gpu-lab shows the folders. Create a private GitHub repo and push; make it public later once polished.
