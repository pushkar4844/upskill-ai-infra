About this roadmap

This is a free, open learning roadmap for GPU and AI infrastructure. It combines three sources: NVIDIA's Solutions Architect, Infrastructure posting (JR2012776, captured verbatim on 2026-10-08), the GPU Bring-Up Field Manual (what to learn: 50 tasks with verified repositories and docs) and the GPU Lab Playbook (how to do it: environments, commands, checks and fixes). Lab IDs (A1 … L2) are the same everywhere.

How links and facts were checked

All 228 external links were re-checked on Oct 8, 2026 (HTTP 200). Version-sensitive facts were re-verified against primary sources the same day: DRA graduated to GA in Kubernetes v1.34; Kueue v0.20 removed the v1beta1 API (use v1beta2, where cohort is now cohortName); the AWS Deep Learning Base OSS GPU AMI ships on Ubuntu 24.04 with DCGM 4 preinstalled; DCGM 4 installs as datacenter-gpu-manager-4-cuda<major>; EC2 GPU quota codes are L-DB2E81BA (On-Demand G/VT) and L-3819A6DF (Spot G/VT). Commands that depend on a release fetch the latest version automatically. Star counts are omitted. Where a command or flag varies by version, the step says to check the README or --help.

Honest notes

The lab commands follow each project's documented usage but have not been run on your machine. Release tags and Helm values change; where a step says “check the README / --help”, do that. Cloud prices are rough estimates.

Your data

There are no accounts, cookies or analytics. Lab progress, self-check ticks and the theme choice are stored in your browser's local storage and never leave your device. Clearing site data resets them.

Contribute

Spotted an outdated command or a broken link? Open an issue or pull request on GitHub. All content lives in plain JSON under content/.
